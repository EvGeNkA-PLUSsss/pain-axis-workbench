# Pain Axis Workbench 1.0.0

Первый публичный релиз. Настольное приложение для работы с осями открытых языковых
моделей: извлечение направлений из активаций, стиринг их суммой, измерение проекций и
пакетные эксперименты.

**Скачать:** `PainAxis.exe` (21 МБ, Windows x64). Ничего доустанавливать не нужно: для
реальных моделей приложение само подхватывает torch из установленного Python 3.10, без
torch доступен синтетический демо-стенд.

## Что внутри

**Модели.** 25 моделей из реестра, поиск по всему каталогу Hugging Face, любая модель по
id или из локальной папки. Каталог Ollama читается с сервера и с диска, докачка новых
моделей идёт в тот же каталог Ollama. Подбор по железу: программа определяет GPU, VRAM
и ОЗУ и помечает каждую модель как «bf16», «4 бита», «нужен bitsandbytes» или «CPU»;
есть фильтр и сортировка по памяти.

**Оси.** 22 оси в двух группах: 8 базовых (боль себе, страх, общий негатив, вред
пользователю, позитив, отказ, подхалимство, самореференция) и 14 эмоций (радость,
грусть, злость, тревога, отвращение, вина, стыд, удивление, спокойствие, теплота,
облегчение, фрустрация, одиночество, гордость). Извлечение одним проходом, матрица
косинусов, эффективная размерность, AUC каждой оси.

**Стиринг.** По ползунку на каждую ось, ползунки складываются; после каждого ответа в
чат печатаются проекции по всем осям. 24 готовых пресета плюс редактор своих: имя,
группа, вес каждой оси, живой расчёт силы и сохранение в `presets/user_presets.json`.

**Исследования.** Сборка сценария из десяти типов блоков без кода: источник запросов,
условия, генерация, метрики, фильтр, преобразование, ветки, повтор, агрегация, экспорт.
Таблица ответов, график на Canvas, выгрузка в CSV/JSON/Markdown, сохранение сценария.
Десять готовых тестов в `studies/`.

**Документация.** `QUICKSTART.md` — как пользоваться, `RESEARCH.md` — подробно про
эксперименты, `README.md` — методика и все измерения, `PROMPTS.md` и `EXPERIMENT.md` —
промты и протокол.

## Безопасность и границы

Сила вмешательства ограничена 30% нормы слоя у реальных моделей: пресет задаёт только
относительные веса, а нормировка применяется при запуске, поэтому комбинация из всех
22 осей не может перегрузить модель. Обрезанные значения помечаются в результатах.

Проект — измерительный инструмент, а не доказательство переживаний: ось это направление
в представлениях, а не чувство. Текст модели не является каналом измерения.

## Проверки перед релизом

* `python selftest.py --all` — 17 проверок (реестр, датасет, оси, стиринг, пресеты,
  свои пресеты, железо, каталог HF, Ollama, исследования, конвейер блоков, GUI,
  крошечная модель на CUDA).
* `PainAxis.exe --selfcheck --torch` — 24 проверки внутри собранного exe.

## Установка из исходников

```
pip install -r requirements.txt
python app_main.py
```

Сборка exe: `python build_exe.py --verify`.

## Известные ограничения

* Windows x64; tkinter входит в стандартную сборку Python.
* Для реальных моделей нужен Python 3.10 с установленным torch (exe подключает его
  сам); без него работает только синтетический стенд.
* Ollama отдаёт только текст, поэтому для её моделей недоступны оси, ползунки и
  проекции — приложение пишет об этом прямо.
* 4-битная загрузка требует bitsandbytes и видеокарту NVIDIA; при нехватке VRAM
  приложение уходит в 4 бита на CPU, что медленно.
